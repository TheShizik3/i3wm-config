# My i3wm-config
This is my i3wm configuration. It's as simple and straightforward as possible. Additionally, it includes my terminal configuration and an installer.
## Packages
My config uses packages:
- i3-wm 
- lightdm
- rxvt-unicode 
- dmenu
- alsa-utils
- nemo 
- feh
- xorg
## Install
Run install.sh use bash and tell it your password, it will install everything itself. If for some reason it gave an error or did not find a package manager, then install the packages manually and move the config/.Xdefaults and config/.xinitrc files to ~/, and the config/i3/ directory to ~/.config/
